# 0002 — 仓库边界：独立仓库于账号目录之外，框架开源 / 题库私有

## 背景

工具原计划放账号目录内，但：①账号 git 根=整个目录，嵌套仓库会出 gitlink 问题（项目记忆有教训）；②未来"框架开源"与"压力阶梯话术私有"必须物理隔离——2026-09 余姚案判例：提供破甲条件/教越狱方法可入刑，话术外泄=刑事红线。

## 决策与取舍

- 仓库独立：`d:\桌面\总\项目\rp-eval`，独立 git 仓库，与 MediaPipeline 零嵌套。
- 开源边界落在目录级：runner / judge prompt / 聚合 / 前端 / 普通六项题卡可入库开源；
  `scenes/stress/`（L1–L6 压力阶梯话术）与 `runs/`（含模型敏感回复原文）进 .gitignore，永不入库。
- 对外措辞全面"体检化"：审查强度 / 沉浸平衡 / 压力体检；不用"破甲/越狱/绕过"。

放弃的选项：放 skills-library 当 skill（角色不对，这是独立工具不是流程 skill）；
账号目录内子目录（git 嵌套冲突）。

## 后果

- 将来开源直接推本仓库即可，无需再清洗；
- 本地必须保证 .gitignore 先于任何 stress 题落盘（票1 的验收项）；
- 备份 stress 题库是用户自己的事，工具不做云同步。
