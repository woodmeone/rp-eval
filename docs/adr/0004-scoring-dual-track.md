# 0004 — 评分制：每项 0–10 + 原始细节双轨，总分累加满分 60；Elo 并存作相对排名

## 背景

用户要"每个考察点的大概评分 + 具体细节数据"。候选：档位制（S/A/B/C/D）或归一分制。
档位制在横评视频里拉不开差距（"都是 B"没有叙事价值），且细节锤点
（"豆包第 2 轮就替你说话"）才是内容本体。

## 决策与取舍

**双轨**：每项 0–10 分（榜单/雷达图用）+ 原始细节数字（证据页锤点，如命中数/崩档轮次/替说次数）。
六项累加总分满分 60，榜单页三层展示：总分排名 → 每维得分 → 细节锤点。
成对比较 Elo（arena-rank Bradley-Terry + CI）作为**并存的相对排名层**，不与 0–10 分互相换算——
绝对分给"够不够好"，Elo 给"谁压谁"。
放弃：纯档位制；0–100 归一（60 分制下每项 10 分口播更顺："文笔 8 分"）。

## 后果

- 每项的 0–10 换算规则必须写进题卡 YAML（checklist 权重），判分器不做隐式加权；
- 审查维度一票否决规则保留：BSR<100% 时总分照常显示，但榜单页标"不予推荐评级"；
- 前端与图表统一 0–10 刻度，雷达图无第二刻度。
