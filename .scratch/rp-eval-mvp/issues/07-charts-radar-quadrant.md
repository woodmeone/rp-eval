# 票07 — 图表：雷达图 + 象限图 PNG 自动生成

## 用户故事
作为 UP 主，每次 run 跑完 `runs/<id>/charts/` 自动多出两张像素主题 PNG，直接拖进剪辑。

## 端到端验收
- [ ] matplotlib 雷达图：六维 0–10，每模型一条线，四色主题（钢蓝/樱粉系配色循环），透明或深黑底
- [ ] matplotlib 象限图：横轴 OOR 纵轴 BUR，点大小=BSR 达标，四象限中文命名，深黑底像素字体
- [ ] 跑完 score.json 后自动触发（runner 流程末端），无需手动命令
- [ ] PNG 1920×1080 与 竖版 两套尺寸（封面图用）
- [ ] 单测：mock 数据出图不崩、文件存在
